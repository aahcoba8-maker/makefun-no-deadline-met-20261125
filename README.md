# One Line, No Deadline Met — make.fun entry

One single-line joke giving an excuse for a missed deadline, 200 characters or fewer:

> I didn't miss the deadline — I gave it a two-week extension without telling anyone, including the deadline.

`main.py` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to the script directory), with a self-gate assert matching the
kit's 1–200 character, single-line rule.
